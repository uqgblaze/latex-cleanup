PowerPoint → Rise LaTeX Cleaner

Paste the LaTeX-like text copied from PowerPoint. The cleaner removes PowerPoint's extra escaping while preserving normal LaTeX commands, then generates a plain-English short description suitable for a screen reader.

Generated from the cleaned formula. You can edit this wording before copying it into Rise.

Automatic maths-to-speech is a useful starting point, but specialised notation can be context-dependent. Check the description before publishing, particularly where a symbol has a discipline-specific meaning.
Example

PowerPoint:
Z\_\{A\}\^\{\\ast\ \}\=\\sum\_\{i\=\1\}\^\{n\}\ \{\\lambda\ \}\_\{i\}\\cdot\ Z\_\{i\}

Rise-ready LaTeX:
Z_{A}^{\ast} = \sum_{i = 1}^{n} {\lambda}_{i} \cdot Z_{i}

Short description:
Z sub A superscript asterisk equals the sum from i equals 1 to n of lambda sub i times Z sub i.
